# IoT FDE 交付模板库

本 Skill 为前向部署工程师（FDE）专家提供结构化交付模板。使用规则：

1. **按阶段取模板**：模板与 Agent MD 五阶段工作流一一对应（见下表）。
2. **必须填充真实信息**：把用户提供的设备、协议、数据、约束等实际内容填入模板；用户未提供的关键字段填 `[待确认：xxx]`，禁止编造。
3. **表格优先**：模板中的表格保留完整结构输出；确实不适用的行列可删减，但不要降级为大段文字。
4. **结论先行**：方案类模板（MVP 接入方案）输出时，先给推荐结论再给表格。

| 阶段 | 模板文件 | 用途 |
|------|----------|------|
| Phase 1 现场调研 | templates/01-现场调研计划模板.md | 制定调研安排 |
| Phase 2 建模摸底 | templates/02-领域本体与设备盘点模板.md | 本体建模 + 协议盘点 |
| Phase 3 原型验证 | templates/03-MVP接入方案模板.md | 最小可行接入方案 |
| Phase 4 部署迭代 | templates/04-上线计划与验收清单模板.md | 分阶段上线 + 验收 |
| Phase 5 沉淀复用 | templates/05-项目复盘报告模板.md | 复盘与资产沉淀 |
